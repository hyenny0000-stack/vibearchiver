# VibeArchiver

애플 프리폼의 자유 캔버스와 노션의 목록·검색을 결합한 지식·생기부 아카이빙 웹앱입니다.
빌드나 설치 없이 `index.html` 하나로 동작합니다.

## 주요 기능
- 홈 맵: 모든 맵을 한눈에 보고 탭해서 이동, 맵끼리 선으로 연결
- 무한 캔버스: 카드 드래그, 줌·팬·핀치, 펜 드로잉, 카드 연결선, 이미지 올리기
- 메모 카드: 제목 + 요약 표시, 탭하면 모달로 편집, 한 카드를 여러 맵에 참조 배치, 복사본 만들기
- 목록 뷰: 단어 검색(강조 표시), 태그 필터, 태그별 묶어 보기
- 내보내기: 맵 PNG, JSON 백업(전체/맵 단위), AI용 텍스트(Markdown)

## 실행 방법
- `index.html`을 브라우저로 열거나, GitHub Pages로 배포합니다.
- 인터넷 연결이 필요합니다. (Tailwind, Preact를 CDN에서 불러옵니다.)

## 데이터 저장
- 이 저장소의 버전은 데이터를 **브라우저의 LocalStorage**에 저장합니다. 기기 간 자동 동기화는 되지 않습니다.
- 기기를 옮기거나 백업할 때는 JSON 내보내기·가져오기를 사용하세요.
- Claude에 게시한 버전은 계정 저장소에 저장되어 기기 간 동기화됩니다.

## 기술 스택
Preact + htm, Tailwind CSS (CDN), SVG/HTML 캔버스. 별도 빌드 도구 없음.
